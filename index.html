TEMA 1

El Selector Universal (*) y el Reset Moderno

Sintaxis: asterisco ( * )

El asterisco * selecciona absolutamente todos los nodos del árbol DOM. Cada navegador aplica estilos predeterminados (User Agent Stylesheet) con márgenes arbitrarios.

margin: 0 & padding: 0: Elimina las separaciones sorpresivas en títulos, listas y el propio body.
box-sizing: border-box: Garantiza que el ancho declarado de una caja incluya el padding y el border sin ensancharla.
⚠️ Error común: Nunca pongas fuentes (`font-family`) ni colores (`color`) dentro del asterisco *, porque rompes la cascada y la herencia natural de CSS.
Código Estándar de la Industria
/* El Reset Universal Infalible */
*, *::before, *::after {
box-sizing: border-box; /* Dimensiones predecibles */
margin: 0; /* Cero espacios fantasma */
padding: 0; /* Relleno limpio */
}
/* En imágenes evita scroll horizontal indeseado */
img, picture, video {
display: block;
max-width: 100%;
}
Incluir `*::before` y `*::after` asegura que los pseudo-elementos también respeten el cálculo de tamaño. Estándar W3C
TEMA 2

Design Tokens con la Pseudo-clase :root

Sintaxis: --nombre-variable

:root es una pseudo-clase que apunta al elemento raíz supremo del documento (equivale a <html> pero con mayor especificidad). Es el lugar oficial para alojar Variables CSS (Custom Properties).

Declaración (`--variable`): Se inicia siempre con dos guiones medios. Ejemplo: --color-marca: #FFC820;.
Lectura (`var()`): Se invoca en cualquier propiedad con var(--color-marca).
⭐ Gran ventaja: Si el cliente te pide cambiar el color corporativo o el redondeo de los botones, lo cambias en una sola línea en :root y se actualiza todo tu sitio web.
Sintaxis CSS Variables
/* Centralización de Tokens en :root */
:root {
--color-primario: #FFC820;
--color-oscuro: #111827;
--radio-tarjeta: 16px;
--sombra-suave: 0 10px 25px rgba(0,0,0,0.08);
}
/* Consumo en componentes */
.tarjeta-curso {
background-color: var(--color-oscuro);
border: 2px solid var(--color-primario);
border-radius: var(--radio-tarjeta);
box-shadow: var(--sombra-suave);
}
Las variables en CSS son reactivas: cambian en tiempo real mediante JavaScript o Media Queries. CSS Custom Properties (Level 1)

TEMA 3

Integración Profesional de Google Fonts

<link> vs @import

Google Fonts nos permite cargar tipografías alojadas en la nube. Sin embargo, hacerlo mal puede destruir la velocidad de carga de tu página web (LCP).

1. Método <link> en el HTML (Recomendado): Permite la descarga en paralelo gracias a rel="preconnect".
2. Evitar @import en CSS: Bloquea la renderización en cascada hasta descargar el archivo externo de fuentes.
3. Font Stack de respaldo: Siempre termina con una fuente genérica: font-family: 'Inter', sans-serif;.
Código Óptimo en <head>
<!-- 1. Acelera la conexión DNS con Google -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<!-- 2. Descarga la tipografía con display=swap -->
<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@400;700&display=swap" rel="stylesheet">
/* 3. Aplicación en CSS con fallback */
body {
font-family: 'Outfit', -apple-system, sans-serif;
}
`display=swap` muestra texto inmediatamente con la fuente del sistema mientras la web font termina de descargar. Core Web Vitals
TEMA 4

La Diferencia: *, :root, html y body

Matriz de Responsabilidad

Muchos desarrolladores novatos mezclan estas configuraciones. Esta es la distribución arquitectónica correcta de cada una:

* (Universal) Todos

Aplica a cada etiqueta existente.

• box-sizing: border-box
• margin: 0
• padding: 0
❌ No colocar fuentes ni colores aquí.
:root Tokens

El contenedor raíz de mayor peso.

• --color-primario
• --espacio-base
• --radio-borde
⭐ Exclusivo para Variables CSS globales.
html Documento

La ventana raíz de la página.

• scroll-behavior: smooth
• font-size: 16px (base rem)
• height: 100%
✓ Controla el scroll y la unidad 1rem.
body Lienzo Visible

El contenedor del contenido visual.

• font-family (Google Font)
• color (color de lectura)
• background-color
✓ Se transmite a los hijos por herencia.
Regla de Oro: La tipografía y el color se declaran en body para que los textos hijos los hereden limpiamente. Herencia en CSS
LABORATORIO EN VIVO

Taller: Boilerplate Global y Tarjeta con Variables

Crea la hoja de estilos base para un portal educativo aplicando la arquitectura global de 4 niveles:

Paso 1 (*): Resetea márgenes, rellenos y activa box-sizing: border-box en todos los elementos.
Paso 2 (:root): Declara --color-marca, --color-fondo y --borde-radio.
Paso 3 (html & body): En html activa scroll-behavior: smooth. En body aplica la Google Font importada.
Paso 4 (Componente): Maqueta una tarjeta que consuma las variables declaradas con var().

DISEÑO GLOBAL ACTIVO

Portal Estudiantil IDAT

Texto renderizado con la tipografía web Outfit de Google Fonts, herencia limpia desde body y colores mapeados desde :root. 

/* 1. Reset Universal */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0; padding: 0;
}

/* 2. Variables Globales */
:root {
  --color-marca: #FFC820;
  --color-fondo: #111827;
  --radio-base: 16px;
}

/* 3. HTML y Body */
html {
  scroll-behavior: smooth;
}
body {
  font-family: 'Outfit', sans-serif;
  color: var(--color-fondo);
}

/* 4. Componente con Variables */
.tarjeta-portal {
  border: 2px solid var(--color-marca);
  border-radius: var(--radio-base);
}
